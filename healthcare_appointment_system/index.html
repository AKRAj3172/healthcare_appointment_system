    What runs under the hood

    Current mode: browser demonstration. HTML/CSS/JavaScript implement an isolated simulation; localStorage provides browser persistence.

    AVL tree: free slots

    Each doctor and date keeps free slots in a balanced tree. Search, insert and delete take O(log n), even in the worst case.

    Hash maps: records

    Patients, doctors and appointments are found by ID in O(1) on average, with chaining for collisions.

    Mutex lock: no double booking

    Checking a slot and taking it happens as one step, so two requests can never win the same slot.

    How patient IDs are stored

    A hash map with 7 buckets and chaining. Each ID is hashed (djb2) to a bucket; IDs that collide share a chain.
